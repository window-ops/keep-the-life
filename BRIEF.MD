| File | What it contains |

| [docs/world.md](docs/world.md) | the fixed rules of the world |
| [docs/canon.md](docs/canon.md) | what each chapter has established so far |
| [docs/style.md](docs/style.md) | the rules of style for directions, dialogue, documents and screens |
| [docs/files.md](docs/files.md) | every file and folder, and which page loads which stylesheet and script |
| [docs/markup.md](docs/markup.md) | the markup of chapters, replies, screens, printed matter and the calculator |
| [docs/interface.md](docs/interface.md) | the reader's settings, keys, toggles and tools |
